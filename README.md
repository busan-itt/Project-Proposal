# Project Proposal

## 부산 신항의 선석 통합운영을 통한 환적 체류시간 저감

자부두·타부두 환적 데이터 분석을 바탕으로 부산 신항의 선석 공동 활용 방안과 기대효과를 제시하는 **개선 제안서 저장소**입니다.

**작성자:** 이주영 · 박준형

### 개선 제안서

**[이주영_박준형_개선제안서.ipynb](이주영_박준형_개선제안서.ipynb)**

위 링크에서 제안서 본문을 확인할 수 있습니다.

## 주요 내용

| 구성 | 내용 |
| :--- | :--- |
| 현황 및 문제점 | 자부두·타부두 환적 과정, 장기 야드 체류 및 환적 방향별 차이 |
| 개선 방안 | 부산 신항 7개 터미널의 선석 공동 활용과 통합운영 검토 |
| 기대효과 | 시뮬레이션을 통한 야드 체류시간·선박 대기시간·터미널 부하율의 개선 가능성 검토 |

## 비교 시나리오

| 시나리오 | 운영 방식 |
| :--- | :--- |
| 기존 운영 | 터미널별로 선석을 독립적으로 운영 |
| 인접 터미널 공유 | 인접한 터미널 간 선석을 공동 활용 |
| 신항 전체 통합운영 | 부산 신항 7개 터미널의 선석을 공동 활용 |
