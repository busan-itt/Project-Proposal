# Project Proposal

## 부산 신항의 선석 통합운영을 통한 환적 체류시간 저감

자부두·타부두 환적 데이터 분석을 바탕으로 부산 신항의 선석 공동 활용 방안과 기대효과를 제시하는 **개선 제안서 저장소**입니다.

제안서는 **"선박 대기시간이 줄면 모선·연결선 일정이 빨리 맞물려 환적 컨테이너의 야드 체류시간도 줄어든다"** 는 가정을 세우고, 선석 통합운영으로 이를 실현할 수 있는지 시뮬레이션으로 검증하는 방안을 담고 있습니다.

**작성자:** 이주영 · 박준형

### 개선 제안서

**[개선제안서.ipynb](개선제안서.ipynb)**

위 링크에서 제안서 본문을 확인할 수 있습니다.

## 주요 내용

| 구성 | 내용 |
| :--- | :--- |
| 핵심 가정 | 선박 대기시간 감소 → 모선·연결선 연계 단축 → 야드 체류시간 감소 |
| 현황 및 문제점 | 자부두·타부두 환적 과정, 장기 야드 체류, 환적 방향별 차이, 선박 지표와 체류시간의 관계 |
| 개선 방안 | 부산 신항 7개 터미널의 선석 통합 배정 기준과 시뮬레이션 검증 절차 |
| 기대효과 | 선박 대기시간(직접 효과)·야드 체류시간(최종 목표)·터미널별 부하율(부작용 점검)의 평가 지표와 결과 해석 기준 |
| 분석 근거 및 용어 | 제안의 근거가 된 분석 자료와 주요 용어 정리 |

## 비교 시나리오

| 시나리오 | 운영 방식 |
| :--- | :--- |
| 기존 운영 | 터미널별로 선석을 독립적으로 운영 |
| 인접 터미널 공유 | 인접한 터미널 간 선석을 공동 활용 |
| 신항 전체 통합운영 | 부산 신항 7개 터미널의 선석을 공동 활용 |
